# What makes it easy

## What it does

Answers a question the owner asked on 15 September 2026. A user of the Praxis
suite told him it was far easier to work with than a plain session, mainly
because it seemed to understand what he meant and get it right first time,
where before he had gone back and forth a great deal.

This records what is actually built into that system to produce that, read out
of its own instruction files, and says which of it Bottega lacks, which it
deliberately does the opposite way, and which it should not copy.

## What done looks like

- `docs/research/WHAT-MAKES-IT-EASY.md` exists and follows
  `docs/research/README.md`.
- The path a user walks is traced with the real text quoted, not paraphrased:
  what starts it, what is asked, in what order.
- The mechanism that captures what was wanted is named and quoted.
- The rules that govern how it talks to a person are quoted.
- Loops, session handoffs, and what it does with git are each answered.
- Bottega's own build path is read alongside, and the page says which of these
  Bottega already has, which it lacks, and which it rejects for a stated
  reason — naming the reason.
- Where the honest answer is that the model did it rather than the system, the
  page says so.
- The folder index lists the page and carries the warning it earns: it was read
  from files and never watched running.
- Nothing is built. No rule, budget, skill, agent definition or check changes.
- The budget check and the tests pass.

## What is out

- Acting on any of it. Which recommendation becomes a change is the owner's
  decision and a separate piece of work.
- Any claim about what that system was observed doing. Nobody ran it.
- Changing `docs/PLAN.md` or `docs/OPEN.md`.
