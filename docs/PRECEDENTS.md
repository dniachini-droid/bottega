# Arguments already had, and settled

The reviewer reads this before it reports, and does not reopen anything in it.

This is not a list of banned subjects. *Why: banning a subject also bans the
real defect that happens to fall inside it. A precedent settles one recurring
argument and leaves everything else reportable.*

**How it grows.** When a review produces a false alarm and the argument is
settled, the settlement is written here — what was reported, why it was not a
defect, and the date. Never a category, always the specific argument.

**How it shrinks.** A precedent whose reason has stopped being true is
deleted. *Why: the same rule as everywhere else here — a precedent nobody can
justify is one nobody dares remove.*
